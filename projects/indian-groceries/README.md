# Indian Groceries 🛒

A responsive grocery-delivery storefront concept with product discovery, categories, cart interactions and a clean e-commerce interface.

## Features
- Product search
- Category filtering
- Add-to-cart workflow
- Responsive product grid
- Cart total calculation
- Mobile-friendly UI

## Tech Stack
HTML5 • CSS3 • JavaScript

## Run
Open `index.html` in a browser.
